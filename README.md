# 🔑 Key Switcher

A lightweight Windows GUI application for quickly switching **Claude Code API keys and models** without manually editing configuration files.

Key Switcher stores API keys securely in an Excel file and allows you to select a key and model from a simple graphical interface. With one click, it updates the Claude Code `settings.json` configuration.

---

## ✨ Features

- 🔑 **Switch Claude Code API Keys**
- 👤 Store multiple API keys with custom nicknames
- 📊 Manage API keys using an Excel file
- 🤖 Switch between different AI models
- ⚡ Apply configuration with one click
- ➕ Add new API keys from the application
- 🗑️ Delete saved API keys
- 🎛️ Simple and lightweight GUI
- 💾 Preserves all other Claude Code settings
- 🚫 No backup files are created
- 🔒 API keys are not displayed in the main dropdown — only nicknames are shown
